# English only — everything committed to this repo is written in English

Repo rule for `aire-server`, registered 2026-07-13 by Bernard's directive. Every byte
that gets committed is written in **English**: README, CLAUDE.md, rules, backlog,
docstrings, code comments, UI strings, log and CLI messages, systemd unit descriptions,
shell-script comments and echoes, commit messages, and PR bodies.

## How to apply

- **Quoted sources originally written in another language** (e.g. the Mecano *"Aire"*
  lyrics in `CLAUDE.md`) appear in English translation, with attribution noting the
  translation.
- **Identifiers follow the same law**: no Spanish variable, function, key, or file
  names (`estado` → `status`, `log-es-la-verdad.md` → `log-is-the-truth.md`).
- **Technical terms and external identifiers** stay in their original form (SDK
  symbols, `doctl`/`az` flags, upstream file names).
- This governs **repo content only**. The conversation register with Bernard (Spanish)
  is a session setting and is unaffected.

On 2026-07-13 the entire repo was translated under this rule. Anything new added in
Spanish is a violation, not a style choice.
